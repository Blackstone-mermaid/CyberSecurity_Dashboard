# CyberWatch SOC Dashboard

A simple cybersecurity dashboard built using Streamlit to analyze and visualize network traffic data from the UNSW-NB15 dataset.

---

## Live App


---

## About the Project

This is a learning project that demonstrates how cybersecurity data can be explored using an interactive dashboard. It helps in understanding network traffic patterns and different types of attacks through visualizations.

---

## Features

* Interactive dashboard built with Streamlit
* Visualizations using Plotly
* Analysis of attack categories and network traffic
* Clean SOC-style interface

---

## Tech Stack

* Python
* Streamlit
* Pandas, NumPy
* Plotly

## Setup and Run

### 1. Clone the Repository

```bash id="clone2"
git clone https://github.com/your-username/cyberwatch-dashboard.git
cd cyberwatch-dashboard
```

### 2. Install Dependencies

```bash id="install2"
pip install -r requirements.txt
```

### 3. Run the App

```bash id="run2"
streamlit run app.py
```
